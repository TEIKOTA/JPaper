# Failure Pattern Seed（テンプレート由来シード）

## 目的と所有権

テンプレート母体・派生プロジェクト群のセッション実測から、どのプロジェクトでも起こりうるプロセス・ツール運用上の失敗だけを移植するシード。**テンプレート所有**であり、派生 repo への同期ではこのファイルを上書きしてよい。

派生 repo 固有の観測はこのファイルへ追記せず、プロジェクト所有・append-only の [`failure-patterns.md`](./failure-patterns.md) に記録する。ドメイン固有の知見はドメインの正本へ昇華する。

## シード

| 症状 | ありがちな間違い | 正しい一手（根拠・昇華先） | 初回発火日 | 最終発火日 |
|---|---|---|---|---|
| git worktree が未 push commit ごと消えた | `/tmp`・`$TMPDIR` 配下に worktree を作った | home 配下に作る（実発生・復旧作業あり。昇華済み: AGENTS.md ガードレール + `scripts/hooks/guard-bash.sh`、ADR 20260729） | 2026-07-29以前 | 2026-07-29以前 |
| 長時間ジョブ待ちでモデル往復を浪費 | `until grep … sleep` の即興ポーリングを再発行し続けた | `scripts/wait-for-marker.sh` 1 回に集約（母体実測 341 回・約 118 分。昇華済み: scripts + ガードレール） | 2026-07-29以前 | 2026-07-29以前 |
| 同一テーマの issue・実装が重複した | 起票・着手前に既存 issue / PR を検索しなかった | `--state all` で検索し重複確認節へ記録（母体で起票 50 分後に別セッションが同テーマ実装。昇華済み: issue テンプレ） | 2026-07-29以前 | 2026-07-29以前 |
| CI がすべて止まり PR が未検証で滞留 | Actions 無料枠の billing 枯渇を障害と誤診して待った | billing 起因かを確認し、検証はローカル（`tests/run-tests.sh`・`scripts/check-pr.sh`）で完結（5 プロジェクトで実害。昇華済み: ADR 20260901-disable-github-actions） | 2026-09-01以前 | 2026-09-01以前 |
| 完了 marker が即誤発火して待機が素通り | 否定形・前回実行の残骸・プロンプトにエコーされる文字列を marker にした | 今回の実行が新規に作る肯定的 marker のみ使う（実測 2026-08-26。昇華済み: `wait-for-marker.sh` ヘッダの投入チェックリスト） | 2026-08-26 | 2026-08-26 |
| GPU ジョブが CPU で黙走し丸 1 日損失 | 資源取得失敗時の劣化フォールバックを許し、進捗計装も無かった | 必須資源は取得失敗で即死＋進捗・ETA の計装（実測 2026-08-04。昇華済み: 同上） | 2026-08-04 | 2026-08-04 |
| 完了・送信の報告が実体と食い違う | ログ末尾・進捗表示・記憶から「できた」と報告した | 集計の正本と実体（プロセス・URL・出力）を確認してから報告（5 プロジェクトで同型再発。昇華済み: AGENTS.md ガードレール） | 2026-09-01以前 | 2026-09-01以前 |
| `-` 始まりのファイル名で grep が常に 0 件 | パス・パターンがオプションと誤解釈されるのに気づかない | パスに `./` を付けるか `--` で区切る（本 repo の横断監査作業で実発生） | 2026-09-01 | 2026-09-01 |
| hook・検査の文字列判定が散文に誤発火 | コマンド文字列全体を正規表現で走査した | コマンド位置アンカー＋区間単位で判定し、散文の回帰テストを添える（2026-09-01 に PR 作成を自己ブロック、2026-09-02 に別パイプライン区間の `.env` で再発。昇華済み: #44） | 2026-09-01 | 2026-09-02 |
